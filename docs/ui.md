# UI contract

The sharing feature is named Groups in English and Grupper in Swedish. Membership and management use group, member and owner; saved content uses group places. Ownership actions use Transfer ownership / Överlåt ägarskap. Family is an audience or a user-chosen name, not a feature name. Internal identifiers and persisted contracts retain their existing names.

Group joining and creation use separate rounded panels with a subtle themed background and border. Each panel contains its own heading, input and action, including inside Join or create another group.

Invitation entry shows four digit boxes backed by one labeled text input with a numeric keyboard and one-time-code autofill. Pasting replaces the complete code, strips non-digits and takes the first four digits; typing and backspace retain native single-input editing. A focus outline surrounds the entry and highlights the next empty box. Joining still requires an explicit Request to join action.

Save options uses an upward-opening custom button list matching the group selector, with separate outlined rows and FilePenLine / Route icons for Save with details / Track route. The closed top group selector uses the same 18px semibold text, retaining the muted count. On phones (700px and narrower), save/group choices, copy destinations, place actions and map-app lists use 18px semibold text, at least 60px rows and wrapping labels. Save/group popup buttons support arrows, Home/End, Escape and focus restoration. An outside primary-button or touch press dismisses the popup and consumes its click, without activating the underlying page control; the next deliberate press works normally. While group/save popups or modal sheets are open, background wheel/touch scrolling is blocked; long lists and sheet contents still scroll internally, without chaining at their edges. Closing restores the prior document overflow and scroll position. Group/save popup scrollbars share the sheet scrollbar styling: slim rounded thumbs using the current muted/surface theme colors, with system arrow buttons hidden where supported. Native system pickers elsewhere retain platform presentation.

The Swedish library search placeholder and accessible label use the compact wording Sök platser.

Both Clear search actions clear the query and blur the search input without focusing it, so clearing does not open or retain the phone keyboard. The no-results action also resets category and visit-status filters.

Modal sheets refresh their scrolling surface after opening and after viewport-width changes settle, retaining the same form controls and scroll position. This is a defensive workaround for displaced touch regions after phone rotation; height-only changes such as keyboard opening do not trigger it. Initial sheet focus does not scroll the page.

Map links in installed Apple web apps use the current browsing context to avoid creating an extra browser sheet during the native map-app handoff. Ordinary browser tabs and other platforms retain a separate map window. The provider chooser, remembered provider, details dropdown and directions share this policy and retain no-opener/no-referrer protection. Native handoff and return behavior require physical-device verification.

The library selector shows the selected library name followed by its live place count before the chevron. With a non-empty search, category filter or visit-status filter, it shows matching / total, including zero matches and filters matching every place. List and Map share the same filtered count; switching libraries resets browsing filters through the existing workspace transition. The count describes only the selected library, including Private places, and has an English/Swedish accessible description. Across phone and desktop layouts, signed-in libraries use the group selector as their visible header, retaining a separate library heading only for screen readers. In non-empty signed-in libraries, Add place is a separate 48px button immediately to the right of the flexible library selector. Active groups show a small muted member count inside the top selector, including empty groups. When the complete group name, middle dot and member count fit at their existing font sizes, they share one baseline; otherwise the count sits beneath the name without a dot. Measured text widths adapt to viewport, font loading, enlarged text, language and live count changes. The dropdown includes Manage group / Hantera grupp after the library choices and before Create/Join; it opens the selected group’s Settings management view with Members focused. There is no separate Members row. Private libraries and retained read-only copies omit the member subtitle and Manage group shortcut. Guest Add place actions retain their existing heading position. The redundant writable-group sharing hint is omitted on all screen sizes; read-only warnings remain visible. Guest headings retain their existing layout.

Groups's Show group places action closes Settings and reveals the chosen group's library, including when that group is already selected.

Standalone Settings actions are content-width and left-aligned above the 700px phone breakpoint. This applies to direct action buttons in stacked sections/forms, installation guidance, disclosures and the name-save row. Phone actions retain their full available width. Existing action heights remain at least 48px. Paired backup actions, selectors and choice lists retain their established layouts. Groups starts with the short sharing/private-places explanation; the per-group members/places explanation appears only when managing a group.

Retry and Try again buttons use a decorative 20px clockwise circular arrow (`RotateCw`) before the label, with standard centred button spacing. This includes device transfer, draft recovery, account refresh, GPS and invitation-code retries. Conditional actions show the icon only while offering retry; Skip for now remains text-only.

Shared-link Open maps and Save a copy use Map and Copy icons. Import confirmation uses Upload; profile Save and group rename Save use Check. Group forms use Plus for Create group and UserPlus for Request to join and Create new code. Group-settings Approve/Decline use Check/UserRoundX, matching the join-request sheet. Export local shared backup uses Download. Transfer ownership uses KeyRound; the remaining optional third-group icon proposals are not applied. These are decorative 20px leading icons with standard button spacing.

Sync now and Check for updates use RefreshCw; Sign out uses LogOut. Use this position uses the LocateFixed crosshair, matching Use current location, while Use photo location uses MapPin. Both Update now entry points use CircleArrowUp, and Show save bar uses PanelBottomOpen. These decorative leading icons retain existing button hierarchy, labels, pending states and actions.

Settings, group management and both editors load with the app, so opening these core flows requires no additional feature request or loading dialog. Category draft state is local to its form; durable writes retain the existing transaction and cancellation rules.

Available place photos in details and editors have a 48px upper-right fullscreen control, matching the map icon. The photo viewer fills the app viewport with the whole image contained against a dark background; a collapse icon remains upper-right and respects safe areas. Collapse or Escape returns to the previous view, scroll position and focused control. The native modal keeps underlying details/editor or fullscreen map inactive; Escape closes only the photo. It uses the existing local photo without additional network requests or changes to saved data. English and Swedish accessible labels are supported.

Synchronous errors and missing methods in browser permission/location APIs are treated as unavailable background location support. They do not prevent startup, Settings or explicit saving. Update prompts use the actual active-worker plus waiting-replacement state, including after a slow first installation; Workbox's external-install timing heuristic alone never offers an update.

Background map changes retain unchanged pin elements and keyboard focus. Pin names/colours update in place; additions, deletions and coordinate changes update the cluster index. Changing language updates zoom controls and cluster accessible labels without resetting the map. A GPS save whose refresh finishes after a library switch cannot reopen its editor in that new library or seed a draft there.

Settings → Install Places opens a native browser installation prompt only when the browser has offered one. Offers are captured at startup, retained while Settings is closed, and consumed once on a deliberate click. While the native dialog is pending, the action is disabled. Dismissal falls back to browser-menu guidance; prompt failure also shows an accessible status. A fresh browser offer enables another attempt. iPhone/iPad (including desktop-mode iPad) instead show a numbered Share → View More (when collapsed) → Add to Home Screen → Add guide with icons and conditional Open as Web App guidance. Android gets its own menu instructions; other browsers retain generic menu guidance. English and Swedish are supported. The section is hidden for standalone/fullscreen app launches, Apple's standalone mode, or after the browser reports installation. Detection is session-only and does not claim that installation can be discovered reliably from an ordinary browser tab.

Apple-device help additionally distinguishes Chrome's `CriOS` marker from Safari and other browsers. Chrome uses Share beside the address bar, Add to Home Screen and Add, with Safari as a fallback when the option is missing; Safari uses its own Share/More steps and conditional Open as Web App switch. Other/embedded browsers offer an explicit guided route through Safari rather than assuming their menus match it. Browser identity tailors help only, never native install capability; user-agent masking can require the fallback. Sources: [Chrome iPhone/iPad help](https://support.google.com/chrome/answer/9658361?co=GENIE.Platform%3DiOS&hl=en) and [Apple Safari guide](https://support.apple.com/guide/iphone/iphea86e5236/ios).

Decorative borders remain unchanged. Touch press feedback, supplemental fine-pointer hover, 2px inset keyboard focus, stable disabled dimensions and existing pending labels apply consistently.
